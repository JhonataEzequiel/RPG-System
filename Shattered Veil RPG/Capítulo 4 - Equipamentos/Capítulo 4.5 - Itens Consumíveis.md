Qualquer item que é gasto após o uso é chamado de Item Consumível. Eles são subdivididos entre Resinas, Itens Arremessáveis, Poções, e Venenos. Utilizar um Item Consumível requer uma quantidade de Ações ou Ações Bônus que dependerá do item. Qualquer Item Consumível pesa 0.5 unidades de Peso.

## Poções

Poções são itens portáteis que garantem um efeito ao seu corpo quando são consumidas. Elas podem ser de Restauração, as quais recuperam parte dos PVs ou PMs de quem as consome, ou de outros tipos variados.

### Poções de Restauração

Ao usar uma Ação Bônus, você bebe a Poção de Restauração e rola os dados de cura normalmente, conforme descrito na Poção. No entanto, se você optar por beber a Poção utilizando três Ações, a cura será maximizada, considerando o valor máximo de todos os dados. A tabela a seguir detalha as Poções de Restauração:

| Item                | Funcionalidade                      | Preço |
| ------------------- | ----------------------------------- | ----- |
| Poção de Cura Menor | Restaura Grau 3 + Con de PVs.       |       |
| Poção de Cura Média | Restaura Grau 6 + Con de PVs.       |       |
| Poção de Cura Maior | Restaura Grau 10 + BP + Con de PVs. |       |
| Poção de Mana Menor | Restaura Grau 3 + Sab de PMs.       |       |
| Poção de Mana Média | Restaura Grau 6 + Sab de PMs.       |       |
| Poção de Mana Maior | Restaura Grau 10 + Sab + BP de PMs. |       |

## Venenos

Os Venenos são aplicados em Armas e munições. Para aplicar um Veneno é necessário uma Ação, e eles tem efeito apenas no próximo Ataque realizado por um objeto envenenado. Caso esteja Furtivo, o custo é uma Ação Bônus. Venenos também podem ter efeitos narrativos diversos, como envenenar a bebida de um nobre. Os Venenos básicos estão detalhados a seguir.

| Item               | Funcionalidade                                                                                                                                                                                 | Preço |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- |
| Veneno de Contato  | O alvo atingido deverá passar em uma Salvaguarda de Constituição CD 12 + BP ou receberá Grau 6 de Dano Venenoso Contínuo por 6 Rodadas. Em caso de sucesso, recebe metade do dano.             |       |
| Veneno Paralisador | O alvo atingido não pode se mover por 6 Rodadas caso falhe numa Salvaguarda de Constituição CD 15 + BP.                                                                                        |       |
| Veneno Sonífero    | O alvo atingido fica Incapacitado por 2 Rodadas caso falhe numa Salvaguarda de Constituição CD 15 + BP.                                                                                        |       |
| Presa de Vespa     | O alvo atingido perde 2 pontos em Destreza, Força, e Constituição por 2 Rodadas caso falhe em uma Salvaguarda de Constituição CD 14 + BP. Em caso de sucesso, o efeito dura apenas uma Rodada. |       |
| Amatoxina          | De imediato o alvo não sofre nenhum efeito. Após 24 horas ele começa a sentir náuseas, e tem a Condição Exaustão 3. A Condição aumenta a cada 6 horas, até Exaustão 6, levando o alvo à morte. |       |
